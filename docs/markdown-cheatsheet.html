Tiga aturan dasar

Kalau cuma ingat tiga hal, ingat ini. Sembilan dari sepuluh artikel yang berantakan gara-gara salah di sini.

1. Beri satu baris kosong di antara blok. Markdown mengenali blok baru dari baris kosong. Tanpa itu, judul dan paragraf bisa menyatu jadi satu paragraf.
2. Pakai ##, jangan #. Judul artikel sudah memakai level tertinggi. Tanda # di badan artikel tidak digayakan sama sekali — hasilnya jadi teks biasa, bukan judul.
3. Baris baru biasa tidak dihitung. Menekan Enter sekali tidak membuat paragraf baru. Butuh satu baris kosong, atau dua spasi di akhir baris kalau memang mau pindah baris tanpa paragraf baru.

Judul & sub-judul

Gunakan ## untuk sub-judul dan ### untuk tingkat di bawahnya. Jangan pakai #.

Tulis

Langkah pertama

Tulis
### Kalau perlu lebih dalam
Hasilnya

Kalau perlu lebih dalam

Jangan pakai #. Di halaman artikel, # tampil sebagai teks biasa — ukurannya sama dengan paragraf dan tidak tebal. Judul artikelnya sendiri sudah memakai level itu, jadi # di badan artikel cuma bikin bingung.
Maksimal tiga tingkat. ## → ### → ####. Lebih dari itu artikelnya susah diikuti; pecah jadi beberapa artikel atau pakai daftar.

Tautan

Format: teks di dalam kurung siku, alamat di dalam kurung biasa. Alamatnya harus lengkap dengan https://.

Tulis

Hasilnya

dokumentasi Ruso

URL mentah otomatis jadi tautan. Menulis https://contoh.com tanpa tanda kurung tetap bisa diklik, tapi lebih rapi kalau diberi teks sendiri.
Tautan internal. Untuk menunjuk artikel lain di situs ini, tulis path-nya: [artikel lain](/blog/inside-the-bytecode).

Gambar

Ada dua jalur, dan ini yang paling sering bikin bingung:

JenisCaraCatatan

Format gambar di badan artikel

Tanda seru, keterangan di kurung siku, URL di kurung biasa. Tidak boleh ada spasi antara ! dan [.

Tulis
![Diagram alur scan](https://contoh.com/diagram.png)
Hasilnya
Keterangan gambar wajib diisi. Teks di dalam [ ] dibaca screen reader dan mesin pencari. Menulis ![](url) bikin gambar tanpa keterangan — kurang baik untuk aksesibilitas.
Ukuran. Gambar otomatis menyesuaikan lebar artikel dan diberi sudut membulat. Yang perlu dijaga hanya ukuran file: di bawah ~300 KB supaya artikel tetap ringan.

Blok kode

Pakai tiga backtick di baris sendiri, dan tiga backtick lagi untuk menutup. Nama bahasa ditulis setelah backtick pembuka.

Tulis
```bash
npm run build
```
Hasilnya
npm run build
Nama bahasa itu opsional dan belum memberi warna. Situs ini belum memakai pewarnaan sintaks, jadi bash, js, dan tanpa nama tampil sama: monospace di dalam kotak. Tulis saja nama bahasanya untuk kejelasan pembaca.
Kalau isi kodenya memuat tiga backtick, pakai empat backtick sebagai pembungkus supaya tidak dianggap penutup.

Rata kolom

Tambahkan titik dua di baris pemisah.

Tulis
| Kiri | Tengah | Kanan |
| :-- | :-: | --: |
| a | b | c |
Hasilnya
KiriTengahKanan

Simbol | di dalam sel. Kalau isi selnya mengandung garis tegak (misalnya perintah shell dengan pipe), tulis dengan backslash: \|. Kalau tidak, kolomnya bergeser.
Tabel tidak bisa memuat blok kode, daftar, atau gambar. Isi sel hanya teks, tautan, dan kode singkat dengan backtick. Butuh daftar? Pakai sub-judul dan daftar biasa.
Tabel lebar di ponsel. Tabel yang kolomnya banyak akan melebar dan bisa di-scroll ke samping. Kalau memungkinkan, batasi jadi 3 kolom.

Jebakan umum

Daftar masalah yang benar-benar muncul saat menulis, dan cara memperbaikinya.

GejalaPenyebabPerbaikan
Judul tidak terlihat sebagai judul Memakai # Ganti jadi ##
Semua teks menempel jadi satu paragraf Tidak ada baris kosong antar blok Beri satu baris kosong di antara blok
Tabel tampil sebagai teks dengan garis tegak Baris pemisah | --- | tidak ada Tambahkan baris pemisah di bawah baris judul
Kolom tabel bergeser Ada | di dalam isi sel Tulis \|
Tanda bintang ikut tampil Ada spasi di dalam ** ** Rapatkan: **tebal**
Gambar tidak muncul, cuma kotak rusak URL bukan alamat gambar langsung, atau http Pakai URL gambar utuh berawalan https://
Gambar tampil kecil / dipotong Itu gambar Cover, dipotong untuk kartu Untuk isi artikel, pakai gambar inline
Daftar centang ada bulatannya Gaya situs belum menghilangkannya Pakai daftar biasa kalau ingin rapi
Garis --- jadi judul besar Menempel langsung di bawah teks Beri baris kosong sebelum dan sesudahnya
Kutipan cuma baris pertama Baris berikutnya tidak diawali > Awali setiap baris kutipan dengan >
Sudah Save tapi artikel tidak ada di situs Status masih draft, atau situs belum di-build ulang Set published, lalu minta build ulang
HTML mentah ikut jalan. Menulis <div> atau <span> di badan artikel akan diteruskan apa adanya ke halaman. Jangan pakai kecuali benar-benar paham — dan jangan pernah menempel HTML dari sumber yang tidak dipercaya.

2Pastikan tiap sub-judul memakai ##, bukan ## tidak digayakan
3Semua tabel punya baris pemisah | --- |Tanpa itu, tabel jadi teks biasa
